# Паспорт отдельного русского тестового набора

Источник: авторский искусственный набор `ml/data/custom_ru.py`; результат `data/raw/custom_ru.csv`. Дата создания06.11.2026. Автор текста и разметки: OpenAI Codex (AI); экспертная человеческая разметка не проводилась. Это явно указанное ограничение, не подтверждение качества русского ML.

100уникальных сообщений:50safe(label0),50fraud(label1). Все language=ru, split=test_only, synthetic=true. Поля: id,text,label,language,scenario,annotation_author,split,synthetic. Метка — сценарное ожидание автора, не ответ модели. Сценарии: бытовые сообщения/учёба/доставка/безопасность/банковские уведомления/работа/хобби/запись/нейтральные URL; поддельный банк/блокировка/приз/доставка/родственник/код/госорганы/инвестиции/аккаунт/возврат. Есть легитимные упоминания кода/банка/денег, тексты без URL и разные варианты социальной инженерии.

Набор синтетический, без персональных данных реальных лиц; нет реальных телефонов, карт, аккаунтов или email. Ссылки исключительно `.test`/`.example`; не открываются. Авторский набор создан для этого проекта, сторонние материалы не копировались. Автоматические проверки не заменяют человеческую экспертизу правдоподобия/разметки. Набор небольшой и не представляет все реальные русскоязычные SMS.

Воспроизводимость: `python -m ml.data.custom_ru` записывает тот же UTF-8 CSV с явными LF-окончаниями строк из отслеживаемых исходных формулировок. `.gitattributes` исключает скрытое преобразование байтов при клонировании. Сам CSV — явное исключение из `.gitignore`, оригинальные и производные UCI-данные остаются локальными.

**Запрещено использовать этот набор для обучения, CV, построения словаря TF-IDF, EDA, настройки правил или порогов.** Модули заданий4–6 читают только `sms_raw.csv`/`sms_clean.csv` UCI. Для будущей калибровки нужен другой независимо созданный набор. Русский пока предполагает словарь правил и URL-анализ (URL-модуль ещё не реализован), полноценная ML-поддержка не заявляется. Казахский исключён согласно [DEV-01](../deviations.md).
