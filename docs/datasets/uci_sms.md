# Паспорт UCI SMS Spam Collection

1. **Источник и авторы:** UCI Machine Learning Repository, dataset228; Almeida, T. & Hidalgo, J. (2011). SMS Spam Collection. DOI [10.24432/C5CC84](https://doi.org/10.24432/C5CC84).
2. **Ссылки:** [официальная карточка](https://archive.ics.uci.edu/dataset/228/sms+spam+collection), [оригинальный ZIP](https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip). Копии GitHub/Kaggle не использованы.
3. **Лицензия:** CC BY4.0 согласно официальной карточке UCI, проверено06.11.2026; [текст лицензии](https://creativecommons.org/licenses/by/4.0/). Оригинальный `readme` содержит историческую атрибуцию и disclaimer, сохранён побайтово; авторам сообщения не отправлялись.
4. **Дата и целостность:** фактическое время загрузки с зоной Asia/Qyzylorda, URL и SHA-256 — в [uci_source.json](uci_source.json). Архив и извлечённые файлы в `data/raw/`, не изменяются и не коммитятся; повторная загрузка сверяет хеш, неожиданное изменение вызывает ошибку. `readme` имеет однобайтовую историческую кодировку, SMS-файл строго декодирован UTF-8.
5. **Язык:** английский основной корпус; сленг, транслитерация, нестандартная грамматика. Это не корпус с подтверждённой построчной языковой разметкой и не данные для обучения русского классификатора.
6. **Фактический объём и структура:**5574строки;4827ham/747spam;0пустых и пропущенных текстов;403точных повторов текста до очистки. Каждая строка — метка, TAB, текст; разделение только по первому TAB сохраняет содержимое. `sms_raw.csv`: id=int64 (номер строки1-based), text=str, label=int64. Метки ham→0,spam→1. Подробности и5редактированных примеров каждого класса — [отчёт загрузки](../reports/03_sms_loading.json); цифры/URL/email скрыты в примерах, исходный CSV сохранён без маскирования.
7. **Классы и назначение:** задача обнаружения спама; spam не тождественен мошенничеству. Никаких результатов классификатора на этом этапе нет. После очистки — stratified70/15/15,seed42, векторизатор fit только train. Собственный русский набор в это разбиение не включается.
8. **Ограничения:** исторический небольшой корпус, дисбаланс, близкие шаблоны, возможное смещение источников/эпохи. Удаление точных/нормализованных дубликатов не исключает все смысловые повторы. Тексты/ссылки корпуса никогда не открываются и не пишутся в application logs. Числа из сторонних копий не подменяют фактический подсчёт оригинального файла.

Команда из корня: `python -m ml.data.load_sms --download`. Работает и из другого каталога при доступности пакета (`PYTHONPATH`/установка проекта): пути данных привязаны к расположению модуля, не машине разработчика. Без `--download` выполняется полностью локальная повторная подготовка.
