## Найденные проблемы и исправления

1. В песочнице исходная попытка pip не имела сетевого доступа; установка выполнена после разрешения. Локальная загрузка Bootstrap также потребовала разрешения.
2. Первый pytest:1passed/6errors, поскольку песочница запрещала чтение стандартного Windows temp-каталога pytest. Повторный запуск с разрешённым доступом выполняет тесты. Это ограничение среды агента, не ошибка приложения.
3. Следующий pytest:6passed/1failed — тест ожидал один пробел в vendor-заголовке Bootstrap, официальный файл содержит два. Тест исправлен нормализацией пробелов.
4. Starlette предупреждал об устаревшем httpx в TestClient. Добавлен рекомендованный тестовым клиентом httpx2 с фиксированными зависимостями; итоговый запуск без предупреждения. Cache pytest направлен в `.cache/pytest`, чтобы избежать конфликта прав ранее созданного кеша.
5. Windows запрещает bind127.0.0.1:8000 (WinError10013), в том числе после разрешения. На8080 сервер запустился, пять реальных GET-запросов дали200. README использует8080. Конкретная системная причина запрета8000 не установлена.
