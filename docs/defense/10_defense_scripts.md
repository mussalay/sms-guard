## Техническая демонстрация на 10–15 минут

1. **0–1 мин — запуск и цель.** Уже работающий http://127.0.0.1:8080/; health должен показывать обе модели. Иначе запуск `.\.venv\Scripts\python.exe -m app` при наличии доверенных артефактов. Не запускать второй сервер на занятом порту.
2. **1–2 мин — вход.** Демоаккаунт из README либо собственный учебный. Показать закрытость истории без сессии, затем войти. Не выводить cookie и токены в демонстрацию IDE.
3. **2–3 мин — безопасный en.** Пример 1: текущий сервис дал SAFE0, P≈.003716. Новый браузерный результат читать фактически; не подменять его скриншотом. Модель делает inference, не поиск готовой строки.
4. **3–4 мин — опасный en и NLP.** Пример 3 дал FRAUDULENT90, P≈.993482. Показать normalization_steps и build_feature_pipeline, различить word/char/manual.

## Резервный план

- **503:** проверить доверенные artifact/metadata и health; не выдавать заготовку за inference. Скриншоты можно показать только как результаты прежнего прогона.
- **Сессия/CSRF:** обновить страницу входа и войти заново. Не отключать защиту ради показа.
- **429:** прекратить многократные отправки и подождать минуту. Перезапуск для обхода не является доказательством корректности лимита.
- **Неожиданная категория:** прочитать фактические score/причины, объяснить FP/FN либо ограничение комбинированного риска. Не считать любой ответ модели правильным по определению.
- **Другая машина:** заранее проверить зависимости, локальные ресурсы, порт и модели. Эти материалы не содержат видео; резервные 3–5 мин нужно записать отдельно.
